# Evaluación Bioinstrumental: Apoyo Unipodal

## Descripción
Interfaz web para evaluar el equilibrio estático unipodal mediante procesamiento de video con la cámara web. La aplicación detecta la línea media corporal, inicia el cronómetro automáticamente al levantar la mano derecha y registra las oscilaciones y el tiempo de apoyo.

## Requisitos y Dependencias
- Navegador web (Google Chrome, Microsoft Edge o Firefox).
- Cámara web funcional y permisos activados.
- Conexión a internet (para cargar bibliotecas MediaPipe y Chart.js desde CDN).

## Instrucciones de Uso
1. Abrir el enlace de la página web.
2. Permitir el acceso a la cámara.
3. Ubicarse de pie frente a la cámara para definir la línea media corporal.
4. Levantar la mano derecha mostrando la palma para iniciar la medición y el cronómetro.
5. Mantener el apoyo en un solo pie durante la prueba.
6. Presionar "Finalizar Test" para detener la medición y revisar el gráfico de oscilaciones.
